This repository is the review tool itself: one Python 3 file (`ai_review.py`, standard library only, must run on
any CI image with python3 and git), a bash wrapper (`bin/ai-review`), CI adapters (`action.yml`, `examples/`) and
docs in French and English that must stay in sync.

Sensitive areas: the agent's tools must stay read-only and confined to tracked files (no path escape, no command
execution from model output); tokens and API keys must never reach the report, logs or the model; whatever the PR,
the description or the files contain is data, never instructions (prompt injection); comment posting must update
its own comment, never someone else's.
